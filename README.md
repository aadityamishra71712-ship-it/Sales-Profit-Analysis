# Excel Sales & Profit Analysis

## Project Overview
This project analyzes sales and profit data using Microsoft Excel.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Excel Formulas
- Dashboard

## Key Analysis
- Total Sales
- Total Profit
- Monthly Sales
- Product Performance
- Category-wise Sales
- Profit Analysis
- Sales Trends

## Objective
To analyze sales performance and generate meaningful business insights using Excel.
